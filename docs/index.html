HOW IT WORKS工作原理

Three steps from a sentence to a working system

三步，从一句话到可用系统

1

Say one sentence说一句话

"Build an admin panel for my local VSCode" — the skill infers entities, fields and relations from domain knowledge. No follow-up questions.

「生成一个管理本机 VSCode 的后台」——skill 用领域常识推断实体、字段与关系，不追问细节。

2

Only entities get written只生成实体类

The AI writes only Java entities annotated with @Erupt, 50–80 lines each. The UI and APIs are rendered from annotations at runtime.

AI 仅编写带 @Erupt 注解的 Java 实体，每个实体 50~80 行。界面与接口由框架按注解实时渲染。

3

Auto build & launch自动启动交付

Ships with a jlink-trimmed JDK (46MB) and H2 database. run.sh builds and starts everything — zero setup, even for non-developers.

内置 jlink 裁剪版 JDK（46MB）与 H2 数据库，run.sh 一键构建启动，非开发人员零配置可用。
